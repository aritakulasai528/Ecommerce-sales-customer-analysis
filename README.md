# E-Commerce Sales & Customer Analysis


## Project Overview

This project analyzes e-commerce sales and customer data using MySQL to identify sales performance, customer behavior, product performance, and key business insights.
The project demonstrates practical SQL skills used by Data Analysts to extract, analyze, and interpret business data.

## Tools & Technologies

- MySQL
- SQL
- GitHub

- ## Database Tables

The project contains five relational tables:

- `customers` — Customer information
- `products` — Product and pricing information
- `orders` — Order details and status
- `order_items` — Products and quantities within each order
- `payments` — Payment methods and payment status

## Key Business Insights

### Customer Analysis

- Arun Kumar was the highest-spending customer with ₹91,000 in non-cancelled purchases.
- Priya Reddy generated ₹82,500 in non-cancelled revenue.
- Rahul Sharma generated ₹63,100 in non-cancelled revenue.
- Repeat customers included Rahul Sharma, Priya Reddy, Arun Kumar, and Neha Reddy.

### Product Analysis

- Laptop generated the highest product revenue at ₹220,000.
- Mouse was the most frequently purchased product with 7 units sold.
- Product performance was ranked within each category using window functions.

### Sales Analysis

- April generated ₹405,100 in non-cancelled revenue.
- May generated ₹12,000 in non-cancelled revenue.
- Total non-cancelled revenue was ₹417,100.
- Average order value was ₹32,084.62.

### Payment Analysis

- UPI was the most frequently used paid payment method.
- Payment methods and payment statuses were analyzed using SQL aggregation.
